


## User Story
**As a user**,
I want to manage accounts visually,
So that I can configure ingestion behavior per account.

## Acceptance Criteria
- Accounts list page (`/accounts`)
- Create account form
- Fields:
  - name
  - institution
  - currency
  - type
  - datelock_from
- Edit datelock date
- Clicking an account navigates to `/accounts/:id`

## UI Notes
- Use Tailwind for layout and spacing
- Simple table or card layout is sufficient

## Out of Scope
- Statement upload
- Metrics or charts
