
## User Story
**As a user**,
I want to see uploaded statements per account,
So that I know what data is available.

## Acceptance Criteria
- Statements table on specific statement detail page
- Columns:
  - filename
  - size
  - status
  - uploaded_at
- Upload button wired to backend
- Table refreshes after upload

## UI Notes
- Tailwind table
- Status badge per row

## Out of Scope
- Parsing or feeding actions
